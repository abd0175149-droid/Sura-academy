# API contract

Sources: ADR-004, `spec/15-api-webhooks-jobs.md`.

## Workflow
1. Edit `contracts/openapi/modules/<module>.yaml` (paths, schemas) and register new error codes in `components/error-codes.yaml`.
2. `npx @redocly/cli lint contracts/openapi/sura-api.v1.yaml`.
3. Write a failing feature test that calls the endpoint and `->assertMatchesContract()`.
4. Implement: FormRequest → Policy → Action → Resource.
5. `bash scripts/gen-api-client.sh`; commit the regenerated client with the change.

## Conventions
- Base `/api/v1`. Paths kebab-case plural nouns; actions as sub-resources (`POST /absence-requests`, `POST /sessions/{id}/end`).
- operationId `<module>.<resource>.<action>`; schemas PascalCase; JSON properties snake_case.
- Auth modes: web SPA cookie (Sanctum, CSRF via `/sanctum/csrf-cookie` + `X-XSRF-TOKEN`); bearer token (mobile, later); child token (`child:<student_id>` scope) only for child endpoints under `/api/v1/child/*`.
- Language: `Accept-Language: ar|en`; error messages always carry both `message_ar` and `message_en`.
- Error envelope (all non-2xx):
```json
{ "error": { "code": "LEDGER_INSUFFICIENT_CREDIT", "message_ar": "…", "message_en": "…", "details": {}, "request_id": "…" } }
```
  Status mapping: 400 malformed · 401 unauthenticated · 403 forbidden (role/scope) · 404 not found (also for out-of-scope ids, to avoid leaking existence) · 409 state conflict (invalid transition) · 422 validation · 429 rate limited · 500 internal.
- Pagination: `?cursor=&limit=` (default 25, max 100) → `{ "data": [...], "next_cursor": "…" | null }`.
- Money `{ "amount_minor": 7200, "currency": "USD" }`; instants ISO-8601 UTC `2027-03-14T22:30:00Z`; local class time `{ "local_time": "17:30", "timezone": "America/New_York" }`.
- Idempotency: required `Idempotency-Key` (UUID) on POSTs creating payments, subscriptions, refunds, manual credits, bank-transfer approvals, checkout sessions. Same key + same body → stored response; same key + different body → 422 `IDEMPOTENCY_KEY_REUSED`; keys kept 24h.
- Webhooks are not part of the public contract; they live under `/webhooks/{area}/{provider}`.
- Breaking changes require `/api/v2` (none planned for R1).

## Dart client
`packages/sura_api` generated by swagger_parser from the bundled spec into `lib/src/generated/` (read-only). App code uses repositories in `features/*/data/` that map generated DTOs to UI models when needed. Interceptors: request id, Accept-Language, XSRF, retry on network errors only (never on 4xx/5xx for POST).
