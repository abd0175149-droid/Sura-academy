## لوحة الإدارة والتحليلات والمؤشرات

لوحة الإدارة يجب أن تكفي لتشغيل الأكاديمية يومياً دون مبرمج، وأولويتها قوائم «ما يحتاج إجراء الآن» قبل الأرقام التجميلية. كل تصدير للبيانات محكوم بالدور ومسجل.

| المعرّف | الميزة | التفاصيل | الأولوية |
| --- | --- | --- | --- |
| ADM-01 | لوحة العمليات الحية | حصص اليوم بحالتها (بدأت، تأخرت المعلمة، لم يدخل أحد)، معلمة غائبة، دفعات فاشلة، استثناءات حضور، تجارب قادمة، تجديدات خلال 7 أيام | R1 |
| ADM-02 | إدارة علاقات الأسر | قائمة بمرشحات، ملف الأسرة بخط زمني لكل الأحداث، ملاحظات، وسوم، مهام متابعة، مراحل العميل المحتمل | R1 |
| ADM-03 | الطلاب | السجل الأكاديمي والتشغيلي، تحديد المستوى، الإسناد والنقل، الإيقاف دون حذف | R1 |
| ADM-04 | المعلمات | الملفات والتوفر والشعب والجودة والمستحقات والوثائق | R1 |
| ADM-05 | الشعب والجدولة | معالج إنشاء الشعبة، الجدول المنشور، قائمة الانتظار، التقويم الرئيسي، التعارضات | R1 |
| ADM-06 | التقييمات والتجارب | مواعيد المقيّمين، النتائج، قرارات التسكين، نتائج التجارب ومعدل تحويلها | R1 |
| ADM-07 | المنهج والمحتوى | محرر المحتوى ومكتبة الوسائط وخطط الدروس | R1 |
| ADM-08 | المالية | الدفعات، الفواتير، الاسترداد، الرصيد المالي، اعتماد التحويلات، تقارير الإيراد والتصدير | R1 |
| ADM-09 | الرصيد والحضور | عارض دفتر الرصيد لكل طالب، قائمة الاستثناءات، القيود اليدوية بسبب | R1 |
| ADM-10 | مراجعة التقارير | العينة المختارة، الإعادة للتعديل، الاعتماد | R1 |
| ADM-11 | الاتصالات | القوالب، الرسائل الجماعية، سجل التسليم | R1 |
| ADM-12 | الإعدادات | كل القيم القابلة للتعديل بإصدارات ومن غيّرها ومتى (القائمة في الملحق) | R1 |
| ADM-13 | سجل التدقيق | بحث بالمستخدم والكيان والفعل والتاريخ، للقراءة فقط | R1 |
| ADM-14 | سجل حماية الطفل | بلاغات مقيدة الوصول لمسؤول الحماية ومدير النظام فقط | R1 |
| ADM-15 | مفاتيح الميزات | تفعيل ميزة لمجموعة محددة قبل تعميمها | R1 |
| ADM-16 | تحليل الأفواج | استبقاء الطلاب حسب شهر الاشتراك والسوق والقناة | R2 |

| المؤشر | التعريف | المستهدف بعد 6 أشهر من الإطلاق |
| --- | --- | --- |
| الطلاب النشطون | طلاب لهم اشتراك نشط أو رصيد غير منتهٍ في نهاية الشهر | حسب خطة النمو |
| تحويل التجربة | اشتركوا ÷ حضروا تجربة، خلال 14 يوماً | ≥ 40% |
| الإلغاء الشهري | ألغوا أو انتهى رصيدهم دون تجديد ÷ النشطين في بداية الشهر | ≤ 7% |
| متوسط الإشغال | طلاب مسجلون ÷ الشعب النشطة | ≥ 3.0 |
| معدل الحضور | حاضر ومتأخر وجزئي ÷ كل حالات الحضور | ≥ 88% |
| إلغاءات المعلمات | جلسات ألغيت لغياب المعلمة دون بديلة ÷ كل الجلسات | ≤ 1% |
| التقارير في موعدها | منشورة قبل الاستحقاق ÷ المستحقة | ≥ 95% |
| نجاح الدخول | دخول ناجح من أول محاولة ÷ محاولات الدخول | ≥ 98% |
| الإيراد الشهري المتكرر | مجموع قيمة الاشتراكات النشطة شهرياً | حسب خطة النمو |
| تكلفة الاستحواذ | إنفاق التسويق ÷ الطلاب المدفوعين الجدد | ≤ 90$ |
| الدفعات الفاشلة المستردة | تحصّلت بعد فشل ÷ كل الفاشلة | ≥ 60% |

التحليلات لا ترسل أسماء الأطفال أو بياناتهم لأي أداة خارجية، وتستخدم معرّفات مستعارة. قائمة الأحداث المتتبعة في الملحق.
