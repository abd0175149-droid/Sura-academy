# CR-003: قياس زمن التحميل لتطبيقات Flutter على الويب

- الحالة: Proposed — مرتبط بالقرار D-22
- القسم المتأثر: `18-non-functional-requirements.md` (بند الأداء)

## السبب
تطبيقات Flutter على الويب ترسم الواجهة داخل لوحة رسم وتحمّل محرك العرض في الزيارة الأولى، وSafari يحصل على بناء JavaScript لا WebAssembly. شرط «LCP أقل من 2.5 ثانية للصفحة الرئيسية لكل بوابة» يصعب تحقيقه في التحميل البارد دون تعريف صريح.

## التغيير المقترح
| الواجهة | قبل | بعد |
| --- | --- | --- |
| الموقع العام | LCP ≤ 2.5 ث | بلا تغيير |
| تطبيق الأسرة وبوابة المعلمة | LCP ≤ 2.5 ث | شاشة افتتاحية HTML بـ LCP ≤ 2.5 ث؛ تفاعلي ≤ 5 ث في التحميل الأول و≤ 2 ث في اللاحق (جهاز متوسط، 4G) |
| لوحة الإدارة | LCP ≤ 2.5 ث | بلا تغيير (Filament) |

## الأثر
- WP-0.5 يقيس الأرقام الفعلية قبل الاعتماد. WP-5.3 يختبر الأرقام المعتمدة.
