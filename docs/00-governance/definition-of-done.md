# تعريف الإنجاز (Definition of Done)

لا تُعلَّم مهمة أو حزمة عمل «منجزة» إلا باستيفاء البنود التالية كلها. وكيل `traceability-checker` يتحقق منها قبل الإغلاق.

## مستوى المهمة (كل بند في tasks.md)

- [ ] اختبار فاشل كُتب أولاً (لمهام المحركات)، ثم نجح.
- [ ] `bash scripts/verify.sh --changed` ناجح.
- [ ] لا نص ظاهر للمستخدم مكتوب في الكود.
- [ ] commit صغير برسالة تذكر الحزمة والمعرّفات.

## مستوى حزمة العمل

### الوظيفة والتتبع
- [ ] كل معرّف مسند للحزمة في `traceability.md` له اختبار آلي يبدأ اسمه بالمعرّف وينجح.
- [ ] كل معايير القبول المكتوبة في قسم الحزمة متحققة، ومثبتة بأمر أو اختبار أو لقطة.
- [ ] لا شيء بُني خارج نطاق الحزمة.

### الجودة
- [ ] `bash scripts/verify.sh --all` ناجح، ومخرجاته ملصقة في `specs/WP-x.y/notes.md`.
- [ ] التغطية: 80% لمنطق العمل، و90% لخدمات المحركات (الرصيد، الفوترة، المستحقات، الجدولة).
- [ ] Larastan بالمستوى المعتمد دون أخطاء جديدة، و`flutter analyze` دون تحذيرات.

### العقد والبيانات
- [ ] OpenAPI محدّث، واختبارات العقد ناجحة، وعميل Dart مُعاد توليده دون تعديل يدوي.
- [ ] الهجرات قابلة للتشغيل على قاعدة فارغة، ولا تعديل لهجرة دُمجت سابقاً.
- [ ] الجداول الجديدة تتبع `data-model-conventions.md`.

### الأمن والخصوصية
- [ ] اختبار لكل دور × كل نقطة نهاية جديدة.
- [ ] الأفعال الحساسة تطلب سبباً وتُسجَّل في التدقيق.
- [ ] مراجعة `privacy-reviewer` لأي حزمة تمس بيانات طفل أو واجهة طفل أو تسجيلاً.
- [ ] مراجعة `security-reviewer` لأي حزمة تضيف نقاط نهاية أو مصادقة أو webhooks.

### الواجهات
- [ ] كل نص بالعربية والإنجليزية.
- [ ] لقطات golden لكل شاشة جديدة بالعربية (RTL) والإنجليزية (LTR)، وبمقياسي خط 1.0 و1.3 على الأقل.
- [ ] مراجعة `rtl-reviewer` لأي حزمة تضيف واجهة.
- [ ] أهداف لمس 44 بكسل على الأقل في واجهة الطفل، وتسميات إمكانية الوصول (Semantics) للعناصر التفاعلية.

### التوثيق والإغلاق
- [ ] `docs/03-plan/status.md` محدّث (الحالة، التاريخ، رابط الفرع أو PR).
- [ ] `traceability.md` محدّث لحالة المعرّفات.
- [ ] أي قرار افتراضي طُبِّق مذكور في `notes.md` بمعرّفه D-xx.
- [ ] `notes.md` يحتوي خطوات عرض يدوية يستطيع صاحب المشروع اتباعها.
- [ ] مراجعات الوكلاء المطلوبة نُفذت، ولا ملاحظة حاجبة مفتوحة.
