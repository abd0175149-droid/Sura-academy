## بوابة ولي الأمر

ولي الأمر هو صاحب الحساب ونقطة التحكم بكل بيانات أبنائه، فكل الموافقات والمدفوعات والتواصل تمر من بوابته. الأوقات تُعرض دائماً بمنطقته الزمنية مع اسمها ظاهراً.

| المعرّف | الميزة | التفاصيل | الأولوية |
| --- | --- | --- | --- |
| PAR-01 | اللوحة الرئيسية | بطاقة لكل طفل: المستوى، الشعبة، الحصة القادمة، الرصيد؛ وتنبيهات الأسرة: دفعة مستحقة، تقرير جديد، واجب، تغيير موعد | R1 |
| PAR-02 | إدارة الأبناء | إضافة طفل وتعديل ملفه ضمن الأسرة نفسها | R1 |
| PAR-03 | ملف الطفل | التسكين وتاريخه، الشعبة واسم المعلمة الأول، سجل الحضور، التقارير، الواجبات والدرجات، التسجيلات المسموحة، المواد | R1 |
| PAR-04 | التقويم | عرض أسبوعي وشهري وقائمة لكل الأبناء، وإضافة أي حصة إلى تقويم الجهاز | R1 |
| PAR-05 | الإبلاغ عن غياب | يوضح قبل الإرسال إن كان الغياب قابلاً للتعويض حسب المهلة والسقف | R1 |
| PAR-06 | طلب تغيير موعد أو شعبة | ينشئ طلباً للعمليات ولا يغير الشعبة تلقائياً | R1 |
| PAR-07 | الاشتراك والرصيد | الخطة، الحصص المستخدمة والمتبقية بلغة مفهومة، موعد التجديد التالي، التجديد التلقائي | R1 |
| PAR-08 | المدفوعات والفواتير | وسائل الدفع المحفوظة عبر البوابة، الفواتير والإيصالات PDF، إعادة محاولة دفعة فاشلة، رفع إثبات تحويل | R1 |
| PAR-09 | الإلغاء والتجميد | إلغاء ذاتي بسهولة الاشتراك نفسها، مع عرض خيار التجميد وسياسة الاسترداد قبل التأكيد | R1 |
| PAR-10 | التقارير | المؤشرات الأسبوعية والتقرير الشهري وتقارير المستوى، مع تأكيد الاطلاع وتنزيل PDF | R1 |
| PAR-11 | الرسائل والدعم | محادثات مع الدعم حسب الموضوع مع مرفقات، ومركز إشعارات داخل التطبيق | R1 |
| PAR-12 | تفضيلات الإشعارات | لكل نوع وقناة، مع ساعات هدوء حسب توقيت الأسرة | R1 |
| PAR-13 | مركز الخصوصية | عرض الموافقات وسحبها (ومنها موافقة التسجيل لكل طفل)، وطلب نسخة من البيانات أو حذف الحساب | R1 |
| PAR-14 | وضع الطفل | تشغيل جلسة الطفل على الجهاز نفسه برمز PIN، والخروج منها بكلمة مرور ولي الأمر | R1 |
| PAR-15 | التجميد الذاتي | تجميد الاشتراك لفترة محددة (الصيف مثلاً) دون فقد الرصيد | R2 |
| PAR-16 | رابط تقويم دائم | اشتراك تقويم ICS يتحدث تلقائياً عند تغيير المواعيد | R2 |
| PAR-17 | ولي أمر ثانٍ | دعوة الأب أو الأم الآخر بصلاحيات يحددها صاحب الحساب | R2 |
| PAR-18 | برنامج الإحالة | رمز للمشاركة ومكافأة على شكل رصيد عند اشتراك الأسرة المحالة | R2 |
| PAR-19 | تعليقات على الواجبات | محادثة قصيرة مع المعلمة حول واجب محدد، ظاهرة للمشرف | R2 |
