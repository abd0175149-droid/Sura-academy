# ADR-010: تسليم Flutter على الويب

- الحالة: Proposed — تُثبَّت الأرقام بعد WP-0.5 · مرتبط بـ CR-003، D-22

## القرار المبدئي
1. البناء: `flutter build web --wasm --no-web-resources-cdn --release`. WebAssembly للمتصفحات المؤهلة مع بديل JavaScript تلقائي.
2. لا موارد من خوادم خارجية: محرك العرض مضمّن، الخطوط (IBM Plex Sans Arabic، Noto Naskh Arabic) أصول داخل الحزمة، و`fontFallbackBaseUrl` يشير إلى نطاقنا.
3. ترويسات العزل (COOP/COEP) تُفعَّل فقط إن أثبتت WP-0.5 أنها لا تكسر صفحة الدفع أو الفيديو، وإلا يعمل العرض بخيط واحد.
4. شجرة إمكانية الوصول مفعلة عند الإقلاع (`SemanticsBinding.instance.ensureSemantics()`).
5. شاشة افتتاحية HTML خفيفة في `web/index.html` بالعربية مع شعار وحالة التحميل.
6. Service Worker مخصص للتثبيت والتخزين المؤقت للأصول (Flutter لا يولد واحداً افتراضياً).
7. سياسة أمن محتوى صارمة تسمح فقط بنطاقاتنا ومزود الفيديو.

## ما تقيسه WP-0.5
زمن الشاشة الافتتاحية والتفاعل على iPad (Safari) وكروم بوك ببناءي WASM وJS، عرض نص مشكول كامل بالخطين، عمل قارئ الشاشة VoiceOver بالعربية، إعادة التوجيه لصفحة الدفع والعودة، تأثير ترويسات العزل.
