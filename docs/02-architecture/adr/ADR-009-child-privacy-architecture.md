# ADR-009: معمارية خصوصية الطفل

- الحالة: Accepted · المصدر: `spec/17` (PRV، SAFE)، COPPA المعدّلة، ICO Children's Code، D-13، D-14

## القرار
1. **العزل:** واجهة الطفل في حزمة `sura_kids`. hook يمنع استيراد حزم التحليلات والإعلانات فيها، وكل رابط خارجي يمر ببوابة أبوية.
2. **الحد الأدنى:** حقول الطفل محصورة في PRV-04، ومخطط قاعدة البيانات لا يحتوي حقولاً لصورة أو بريد أو عنوان للطفل.
3. **الموافقة:** نسخ الوثائق القانونية مخزنة، وكل موافقة صف لا يُعدَّل، والسحب صف جديد. خطوة الموافقة الأبوية القابلة للتحقق تسبق إنشاء ملف الطفل بواجهة `VpcMethod` قابلة للتبديل (D-13).
4. **عدم التسرب:** معالج سجلات ينقي الحقول الشخصية؛ Sentry دون بيانات شخصية؛ أحداث التحليلات بمعرّفات معتمة ولا تُرسل من وضع الطفل.
5. **الحذف:** فصل البيانات الشخصية عن السجلات المالية (D-14) ومهام احتفاظ مجدولة.
6. **الحماية:** زر البلاغ ينشئ بلاغاً يصل لمسؤول الحماية فوراً بقناة ذات أولوية، والوصول للبلاغات مقيد بدورين.
7. **الذكاء الاصطناعي:** لا بيانات طفل في أي مدخلات لنموذج (ADR-012).
