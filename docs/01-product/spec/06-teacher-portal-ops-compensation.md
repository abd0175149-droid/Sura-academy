## بوابة المعلمة وعمليات المعلمات والمستحقات

بوابة المعلمة تُعرض بتوقيت عمّان، وتجمع كل ما تحتاجه قبل الحصة وأثناءها وبعدها في شاشة واحدة. المعلمة ترى مستحقاتها بشفافية لكنها لا تملك أي صلاحية مالية.

### بوابة المعلمة

| المعرّف | الميزة | التفاصيل | الأولوية |
| --- | --- | --- | --- |
| TCH-01 | لوحة اليوم | حصص اليوم بتوقيت عمّان، تقارير متأخرة، تسليمات بانتظار التصحيح، تنبيهات تحول التوقيت الصيفي | R1 |
| TCH-02 | الجدول | عرض يومي وأسبوعي لكل الشعب المسندة مع علامات الإلغاء والتأجيل | R1 |
| TCH-03 | صفحة الشعبة | الكود والمستوى والموعد، الطلاب بأسمائهم الأولى ومستوياتهم وملاحظات التعلم فقط، تقدم المنهج، ملخص الحضور | R1 |
| TCH-04 | مساحة الحصة | الفيديو + قائمة الحضور + خطة الدرس + الملاحظات + إنهاء الحصة (تفاصيلها في قسم الفصل الافتراضي) | R1 |
| TCH-05 | تأكيد الحضور | الحالات المقترحة آلياً تُؤكد خلال 12 ساعة؛ بعدها تُقفل ولا تُعدّل إلا بالمشرف | R1 |
| TCH-06 | تقدم المنهج | تحديد الدرس الذي غطّته كل حصة، فيُملأ ملخص الشعبة الأسبوعي تلقائياً | R1 |
| TCH-07 | الواجبات والتصحيح | إنشاء واجب، متابعة التسليمات، درجة أو معيار تقييم، ملاحظة نصية | R1 |
| TCH-08 | التقارير المتدرجة | مؤشرات سريعة لكل طالب، ملخص للشعبة، تقرير شهري مفصل، مع قوالب جاهزة | R1 |
| TCH-09 | التوفر والإجازات | فترات أسبوعية بتوقيت عمّان، استثناءات، طلب إجازة بموافقة الإدارة | R1 |
| TCH-10 | الإبلاغ عن غياب طارئ | يصل فوراً للعمليات ويبدأ البحث عن بديلة | R1 |
| TCH-11 | طلب تغيير موعد | طلب للعمليات، لا يغير الموعد مباشرة | R1 |
| TCH-12 | كشف المستحقات | الشعب المؤهلة، الحصص المنفذة، المعادلة، التعديلات، الحالة؛ مع زر اعتراض ينشئ تذكرة للمالية | R1 |
| TCH-13 | ملاحظة صوتية على الواجب | تسجيل تعليق صوتي قصير للطالب | R2 |
| TCH-14 | مكتبة التدريب | مواد التدريب وتتبع إكمالها | R2 |

### عمليات المعلمات في لوحة الإدارة

| المعرّف | الميزة | التفاصيل | الأولوية |
| --- | --- | --- | --- |
| TOP-01 | مسار التأهيل | طلب، فرز، مقابلة بنموذج تقييم، وثائق (منها شهادة عدم المحكومية)، تدريب، حصة مراقبة، اعتماد، تفعيل | R1 سجلات، R2 سير عمل كامل |
| TOP-02 | ملف المعلمة | اللغات، المؤهلات، المستويات المؤهلة لها، الحد الأقصى للشعب، البيانات البنكية مشفرة، الوثائق مع تواريخ انتهائها | R1 |
| TOP-03 | الإقرارات | قبول العقد ومدونة السلوك وسياسة حماية الطفل بإصداراتها | R1 |
| TOP-04 | الجودة | نماذج مراقبة الحصص، ملاحظات المشرف، مؤشرات المعلمة: الالتزام بالمواعيد، التقارير في وقتها، استبقاء الطلاب | R2 |
| TOP-05 | الإيقاف والإنهاء | منع إسناد شعب جديدة، وقائمة بحصصها المستقبلية لإعادة إسنادها قبل الإيقاف | R1 |

### محرك المستحقات

| المعرّف | القاعدة | التفاصيل | الأولوية |
| --- | --- | --- | --- |
| PAY-01 | وحدة الحساب | الحصة المنفذة: أجر الشعبة ÷ 8 لمن درّستها فعلاً، في كل الحالات بما فيها البديلة | R1 |
| PAY-02 | الأجر الهجين | الأساس + مبلغ لكل طالب مسجل؛ القيم الافتراضية 35 و5 دنانير، أي 45 و50 و55 ديناراً لشعب من 2 و3 و4 طلاب | R1 |
| PAY-03 | العلاوة الليلية | 15% للحصص التي تبدأ بعد 22:00 بتوقيت عمّان | R1 |
| PAY-04 | التغطية العاجلة | مبلغ إضافي للبديلة عند تكليف أقل من 24 ساعة قبل الحصة | R1 |
| PAY-05 | التعديلات | إضافة أو خصم بسبب مكتوب وموافقة المالية، مسجلة في التدقيق | R1 |
| PAY-06 | الدورة الشهرية | احتساب آلي أول كل شهر، مراجعة واعتماد المالية، ثم ملف تحويل بنكي وتسجيل مرجع الدفع | R1 احتساب وتصدير، R2 سير اعتماد كامل |
| PAY-07 | استثناء السعر | سعر خاص لمعلمة أو شعبة بصلاحية المالية أو مدير النظام فقط | R1 |
