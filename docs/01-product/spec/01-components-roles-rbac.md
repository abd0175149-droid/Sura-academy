## مكونات المنصة والأدوار والصلاحيات

المنصة تطبيق ويب متجاوب واحد بأربع واجهات، يخدمه خادم واحد مقسم إلى وحدات. الصلاحية تُفحص في الخادم لكل طلب حسب الدور ونطاق البيانات، لا في الواجهة.

| المكوّن | المستخدمون | الوظيفة | الأولوية |
| --- | --- | --- | --- |
| الموقع العام | الزوار | التعريف بالبرامج والأسعار والجدول المنشور، والتسجيل، مع تحسين محركات البحث بالعربية والإنجليزية | R1 |
| تطبيق الأسرة | ولي الأمر والطالب | بوابة ولي الأمر ووضع الطفل على الجهاز نفسه، قابل للتثبيت كتطبيق ويب (PWA) | R1 |
| بوابة المعلمة | المعلمات | الجدول ومساحة الحصة والحضور والواجبات والتقارير والتوفر والمستحقات | R1 |
| لوحة الإدارة | العمليات والإشراف والمالية والمحتوى ومدير النظام | تشغيل الأكاديمية اليومي دون الرجوع للمبرمج | R1 |
| خادم API ووحداته | كل الواجهات | منطق العمل والقواعد والصلاحيات | R1 |
| خدمة المهام الخلفية | النظام | التذكيرات والتجديد والتحصيل وتوليد الجلسات وحذف البيانات المنتهية | R1 |
| طبقة التكاملات | النظام | محوّلات لمزودي الفيديو والدفع والرسائل قابلة للتبديل | R1 |
| تطبيقات iOS وAndroid أصلية | الأسرة | بعد استقرار تطبيق الويب وثبات الطلب | R3 |

| الدور | نطاق البيانات | أهم الصلاحيات | ممنوع عليه | التحقق الثنائي |
| --- | --- | --- | --- | --- |
| ولي الأمر | أسرته فقط | إدارة الأبناء، الحجز، الدفع، الإبلاغ عن الغياب، التقارير، التسجيلات، الموافقات | بيانات الأسر الأخرى وبيانات اتصال المعلمة | اختياري |
| الطالب | نفسه فقط | دخول حصصه، المحتوى، الواجبات، تسجيلات شعبته | أي معلومة مالية أو بيانات اتصال | لا، رمز PIN |
| المعلمة | شعبها المسندة فقط | الحضور، الواجبات، التقارير، التوفر، كشف مستحقاتها | الأسعار والدفعات والأرصدة وبيانات اتصال الأسر | إلزامي |
| المشرف الأكاديمي | كل البيانات الأكاديمية | التسكين، مراجعة التقارير، تقييم الجودة، تعديل حضور مقفل بسبب | الدفعات والإعدادات التقنية | إلزامي |
| العمليات وخدمة العملاء | الأسر والطلاب والشعب | التسجيل، الجدولة، النقل بين الشعب، التذاكر، الاستثناءات | الاسترداد والأسعار والإعدادات الحساسة | إلزامي |
| المالية | البيانات المالية | الفواتير، الاسترداد، الرصيد المالي، اعتماد التحويلات والمستحقات | تعديل المستوى أو الحضور | إلزامي |
| مدير المحتوى | المنهج والمحتوى والقوالب | إنشاء المحتوى ونشره وأرشفته | بيانات الأسر والمالية | إلزامي |
| مدير النظام | كل البيانات | الإعدادات، التكاملات، الأدوار، سجل التدقيق | لا شيء، وكل فعله مسجل | إلزامي |
| الزائر | الصفحات العامة | التصفح، إنشاء حساب، قائمة الانتظار | كل ما بعد تسجيل الدخول | — |

| المعرّف | متطلب نموذج الصلاحيات | الأولوية |
| --- | --- | --- |
| RBAC-01 | صلاحيات بمفاتيح مسماة مثل `attendance.mark` و`payments.refund` تُجمع في أدوار، والمستخدم قد يحمل أكثر من دور | R1 |
| RBAC-02 | كل استعلام يمر بسياسة نطاق: ولي الأمر بمعرّف أسرته، والمعلمة بالشعب المسندة لها، والطالب بمعرّفه | R1 |
| RBAC-03 | لا زر في الواجهة دون صلاحية مقابلة في الخادم، مع اختبار آلي لكل دور على كل نقطة API | R1 |
| RBAC-04 | الأفعال الحساسة (رصيد يدوي، استرداد، تعديل حضور مقفل، تغيير سعر) تطلب سبباً مكتوباً وتُسجَّل في سجل التدقيق | R1 |
| RBAC-05 | مراجعة ربع سنوية لصلاحيات الموظفين وإلغاء فوري عند انتهاء العمل | R1 |
| RBAC-06 | موافقة شخص ثانٍ على الاسترداد أو الرصيد اليدوي فوق حد تحدده الإعدادات | R2 |
| RBAC-07 | «العرض كمستخدم» للدعم، للقراءة فقط وبسبب مكتوب ومسجل، ولا يشمل حسابات الأطفال | R2 |
