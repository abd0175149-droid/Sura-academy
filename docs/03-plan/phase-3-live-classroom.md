# المرحلة 3: الفصل الافتراضي (الأسابيع 12–17)

**الهدف:** حصة مباشرة آمنة بدخول برمز قصير العمر، وأدوار مضبوطة، وحضور مقترح آلياً، وتسجيل يحترم الموافقات. مزود الفيديو محسوم في ADR-005.

---

### WP-3.1 محوّل الفيديو والغرف

| البند | القيمة |
| --- | --- |
| النافذة | الأسابيع 12–13 |
| يعتمد على | WP-0.4، WP-2.2 |
| القرارات | D-20 (محسوم) |
| المتطلبات | CLS-01، CLS-02، CLS-03، CLS-04، CLS-05، CLS-06، CLS-13، CLS-15 (الخلفية) · SAFE-03 · SAFE-05 · STU-04 (الخلفية) |
| اقرأ فقط | `spec/05-live-classroom.md` · `spec/17` (SAFE-03، SAFE-05) · ADR-005 · مهارة child-privacy (قسم الحصة) |
| المراجعات | security-reviewer · privacy-reviewer |

**المخرجات:**
1. **الواجهة والغرف:**
   - `VideoProvider` وتنفيذه حسب ADR-005.
   - دورة حياة `live_rooms`: إنشاء مسبق، إغلاق بعد النهاية بالإعداد.
2. **الدخول:**
   - نقطة الدخول تصدر رمزاً قصير العمر لكل مستخدم وجلسة ودور (CLS-03)، داخل النافذة فقط (CLS-02)، دون روابط ثابتة.
   - سجل الرموز `join_token_log`.
3. **الأدوار ومنع الغرباء:**
   - المعلمة مضيفة؛ الطالب لا يكتم غيره ولا يشارك الشاشة افتراضياً (CLS-04).
   - مشاركة الشاشة والمقاطع الصوتية للمعلمة (CLS-06).
   - منع الغرباء (CLS-05): الطلاب المسجلون بما فيهم مقعد التجربة، والمعلمة أو البديلة المكلفة، والمشرف.
4. **دخول البديلة والمشرف:**
   - البديلة للحصة المحددة فقط، والمشرف يظهر باسم «مشرفة» (CLS-13).
   - دخول المشرف ظاهر ومسجل (SAFE-05).
5. **الدردشة (SAFE-03):** عامة فقط، ولا رسائل خاصة.
6. **الرابط الاحتياطي (CLS-15):** يُولَّد عند تعطل المزود، مع تسجيل السبب.

**الاختبارات:**
- حدود النافذة بتوقيت UTC.
- رموز الأدوار.
- رفض غير المسجل.
- قبول مقعد التجربة.
- رفض المعلمة الأصلية بعد الاستبدال.
- تسجيل دخول المشرف.

**معايير القبول:**
- [ ] المراجعتان دون ملاحظة حاجبة.
- [ ] كل المعرّفات مختبرة.

### WP-3.2 أحداث المشاركين ومعالجة نهاية الجلسة

| البند | القيمة |
| --- | --- |
| النافذة | الأسابيع 13–14 |
| يعتمد على | WP-2.3، WP-3.1 |
| المتطلبات | CLS-07 (حفظ الدردشة) · CLS-09 · CLS-11 (بيانات المساحة) · CLS-12 (توجيه البلاغ) · TCH-04 (الخلفية) · ATT-01 (المدخلات) |
| اقرأ فقط | `spec/05-live-classroom.md` · `spec/09` (ATT-01، ATT-08) · `spec/15` (webhooks الفيديو، المهام) · مهارة credit-ledger (قسم نهاية الجلسة) |
| المراجعات | ledger-auditor · privacy-reviewer |

**المخرجات:**
1. **webhooks الفيديو:** الدخول، الخروج، انتهاء الغرفة، جاهزية التسجيل. تخزين في `participant_events` (إضافة فقط).
2. **حاسبة الحضور المقترح (CLS-09):**
   - تجمع مقاطع إعادة الاتصال.
   - تحسب أول دخول ودقائق الحضور.
   - تقترح PRESENT أو LATE أو PARTIAL حسب الإعدادات.
3. **حالة الجلسة ومعالجتها:** انتقالات البدء والنهاية، ثم إطلاق المعالجة مرة واحدة إلى الدفتر (ATT-08).
4. **بيانات مساحة عمل المعلمة (CLS-11، TCH-04):** القائمة بالحضور المقترح، خطة الدرس، الملاحظات، المؤشرات السريعة، قائمة الإنهاء.
5. **بلاغ الطوارئ (CLS-12):** يوجَّه فوراً للعمليات ومسؤول الحماية بإشعار ذي أولوية.
6. **حفظ الدردشة (CLS-07):** بوسم الاحتفاظ (D-15).

**الاختبارات:**
- أحداث مكررة وبغير ترتيبها.
- تجميع إعادة الاتصال.
- حد التأخر والحضور الجزئي.
- المعالجة مرة واحدة.
- توجيه البلاغ.

**معايير القبول:**
- [ ] ledger-auditor دون ملاحظة حاجبة.

| المراجعات | privacy-reviewer · security-reviewer |

**المخرجات:**
1. **قاعدة بدء التسجيل (D-11):** موافقة كل حاضر، ومؤشر «التسجيل متوقف» للمعلمة.
2. **النسخ والحذف من المزود (D-16):** مهمة تنسخ التسجيل إلى S3 في eu-central-1 ثم تحذفه من المزود، مع إعادة المحاولة.
3. **الوصول والسجل (SEC-10):** لأسر طلاب الشعبة والإدارة فقط، برابط موقع لمدة 10 دقائق، مع سجل وصول.
4. **الحذف الآلي:** 30 يوماً للأسر و90 للإدارة.
5. **الموافقات والطالب:**
   - أثر سحب الموافقة.
   - واجهة الطالب لتسجيلات شعبته (STU-08).

**الاختبارات:**
- مصفوفة الموافقة: الكل، لا أحد، جزئي، طالب تجربة.
- نطاق الوصول.
- انتهاء الرابط.
- مهام الحذف.
- فشل النسخ وإعادته.

### WP-3.4 واجهة الفصل في Flutter

| البند | القيمة |
| --- | --- |
| النافذة | الأسابيع 13–15 (حرِج للتجربة م2) |
| يعتمد على | WP-1.6، WP-3.1، WP-3.2 |
| المتطلبات | CLS-01، CLS-04، CLS-06، CLS-07، CLS-08، CLS-09، CLS-11، CLS-12، CLS-14 (الواجهة) · STU-03، STU-04 · TCH-04 · SAFE-03، SAFE-05 (الواجهة) · STU-01 (الحد الأدنى: إدخال الرمز وبطاقة الحصة القادمة) |
| اقرأ فقط | `spec/05-live-classroom.md` · `spec/04` (STU-01، STU-03، STU-04) · `spec/06` (TCH-04) · ADR-005 · مهارتا arabic-rtl-ui وchild-privacy |
| المراجعات | rtl-reviewer · privacy-reviewer |

**المخرجات:**
1. **حزمة `sura_classroom`:** تنفيذ `VideoClient`.
2. **عرض الطالب:**
   - شبكة تتكيف مع 2 إلى 4 مشاركين (CLS-01).
   - رفع اليد والتفاعلات (CLS-08).
   - وضع الاتصال الضعيف بالتحول للصوت تلقائياً (CLS-14).
3. **قبل الحصة:**
   - فحص الجهاز (STU-03): الكاميرا والميكروفون والسماعة والسرعة، بتعليمات مصورة وصوتية.
   - دخول بزر واحد مع حالة «انتظر» قبل النافذة (STU-04).
4. **مساحة عمل المعلمة (CLS-11، TCH-04):**
   - فيديو بجانبه القائمة بالحضور المقترح، وخطة الدرس، والملاحظات، والمؤشرات السريعة، وقائمة الإنهاء.
   - أدوات التحكم (CLS-04) ومشاركة الشاشة (CLS-06).
   - زر الطوارئ (CLS-12).
5. **الدردشة العامة (CLS-07):** المعلمة تستطيع إيقافها.
6. **الحد الأدنى من وضع الطفل في تطبيق الأسرة:** إدخال الرمز على جهاز مفوّض، وبطاقة الحصة القادمة بزر الدخول.

**الاختبارات:**
- اختبارات widget للأدوار وأدوات التحكم.
- لقطات golden بالعربية والإنجليزية.
- اختبار تكامل بعميل فيديو وهمي.
- قائمة اختبار يدوي على Chrome وSafari في iPad.

**معايير القبول:**
- [ ] زمن الدخول على بيئة التجربة < 10 ث عند 95% على أجهزة الاختبار، والقياس في `notes.md`.
