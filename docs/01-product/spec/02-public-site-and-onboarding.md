## الموقع العام والتسجيل والتهيئة

المسار من الزيارة إلى الحصة التجريبية يجب أن يكتمل دون تدخل الإدارة في الحالات العادية. النقطة الأهم فيه هي حجز مقعد تجريبي في شعبة حقيقية من الجدول المنشور.

### الموقع العام

| المعرّف | الميزة | التفاصيل | الأولوية |
| --- | --- | --- | --- |
| PUB-01 | الصفحة الرئيسية | رسالة القيمة، البرامج، طريقة العمل، لمحة الأسعار، عناصر الثقة، الأسئلة الشائعة، زر «احجز حصة تجريبية» | R1 |
| PUB-02 | صفحات البرامج والمراحل | العربية، الثقافة الإسلامية، القيم؛ المستويات ومخرجاتها والأعمار | R1 |
| PUB-03 | صفحة الأسعار | تُقرأ من محرك التسعير، وتعرض الباقات العائلية والعملة المحلية التقريبية | R1 |
| PUB-04 | الجدول المنشور | تصفح الشعب المفتوحة حسب المنطقة والعمر والمستوى مع المقاعد المتبقية، دون أي بيانات للطلاب | R1 |
| PUB-05 | السياسات القانونية | الشروط، الخصوصية، إشعار خصوصية الأطفال لأولياء الأمور، الاسترداد حسب السوق، سياسة حماية الطفل؛ كلها بإصدارات | R1 |
| PUB-06 | التواصل | نموذج تواصل ورابط محادثة واتساب مباشر | R1 |
| PUB-07 | اللغتان وتحسين البحث | تبديل عربي/إنجليزي مع hreflang وsitemap وبيانات Open Graph، والعربية من اليمين | R1 |
| PUB-08 | قائمة الانتظار وجمع العملاء المحتملين | نموذج قصير يحفظ مصدر الزيارة (UTM) ورمز الإحالة | R1 |
| PUB-09 | صفحة التوظيف | طلب انضمام المعلمات يدخل مباشرة إلى مسار التأهيل | R1 |
| PUB-10 | موافقة ملفات الارتباط | الأساسية فقط افتراضياً، وأي تتبع تسويقي بموافقة صريحة وفي الصفحات العامة فقط | R1 |
| PUB-11 | المدونة والمقالات | من نظام المحتوى، لجذب البحث العضوي | R2 |
| PUB-12 | صفحات الإحالة | صفحة هبوط برمز إحالة الأسرة ومكافأتها | R2 |

### التسجيل والتهيئة

| المعرّف | الميزة | التفاصيل | الأولوية |
| --- | --- | --- | --- |
| ONB-01 | حساب ولي الأمر | الاسم، البريد، الهاتف برمز الدولة، الدولة، المنطقة الزمنية (تُستنتج وتُعدّل)، لغة التواصل، كلمة المرور، الموافقات مع الإصدار والوقت | R1 |
| ONB-02 | التحقق | رابط تفعيل بالبريد ورمز OTP للهاتف، مع مؤقت إعادة الإرسال وحد للمحاولات | R1 |
| ONB-03 | إضافة طفل بأقل البيانات | الاسم الأول، الشهر والسنة للميلاد، اللغة الأساسية، مستوى العربية التقديري، أسئلة قصيرة عن القراءة والكتابة والمحادثة؛ لا صورة ولا بريد للطفل | R1 |
| ONB-04 | تنبيه الملاحظات | حقل الملاحظات يحذّر من إدخال بيانات طبية غير لازمة | R1 |
| ONB-05 | اختبار تحديد مستوى أولي | 10–15 دقيقة أونلاين، تصحيح آلي، يقترح نطاق مستوى | R1 |
| ONB-06 | اختيار المسار بعد الاختبار | نتيجة واضحة: حجز تجربة مباشرة في شعبة مناسبة، أو مقابلة تقييم شفوية للحالات الحدّية والصغار | R1 |
| ONB-07 | حجز مقابلة التقييم | مواعيد ينشرها المقيّمون تُعرض بتوقيت الأسرة، مع ملف تقويم ورابط الاجتماع والتذكيرات | R1 |
| ONB-08 | حجز المقعد التجريبي | اختيار مقعد في شعبة حقيقية من الجدول المنشور، أو الانضمام لقائمة انتظار | R1 |
| ONB-09 | أهلية التجربة | تجربة واحدة لكل طفل؛ كشف التكرار بالهاتف الموثق والاسم وتاريخ الميلاد وبصمة وسيلة الدفع | R1 |
| ONB-10 | العرض والدفع بعد التجربة | الخطة المقترحة، الخصم العائلي التلقائي، القسيمة، ثم الدفع | R1 |
| ONB-11 | متتبع التقدم | شريط يوضح للأسرة أين وصلت: الحساب، الطفل، المستوى، التجربة، الاشتراك | R1 |
| ONB-12 | تسجيل بمساعدة الإدارة | العمليات تنشئ الأسرة وترسل رابط دعوة لإكمال الموافقات وكلمة المرور | R1 |
| ONB-13 | تفضيلات المواعيد | تُطلب فقط لقائمة الانتظار والحالات الخاصة، وتُحفظ بتوقيت UTC | R1 |
| ONB-14 | الدخول عبر Google وApple | تسجيل أسرع لأولياء الأمور فقط | R3 |
