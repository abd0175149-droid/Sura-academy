## المحتوى والمنهج والتقييم والواجبات والتقارير

المحتوى منفصل عن الكود ويديره مدير المحتوى دون مبرمج، والنص العربي يجب أن يُعرض مشكولاً بخط يدعم التشكيل الكامل. التقارير متدرجة حتى لا تتحول إلى عبء غير مدفوع على المعلمة.

### المنهج والمحتوى

| المعرّف | الميزة | التفاصيل | الأولوية |
| --- | --- | --- | --- |
| CNT-01 | الهرم | البرنامج ← المرحلة ← المستوى ← الوحدة ← الدرس ← عنصر المحتوى | R1 |
| CNT-02 | أنواع العناصر | صفحة نصية مشكولة، فيديو، صوت نطق، ورقة عمل PDF، صورة، رابط خارجي | R1 |
| CNT-03 | الظهور | للطالب أو المعلمة أو ولي الأمر أو عام | R1 |
| CNT-04 | خطة الدرس | الأهداف، المفردات، الأنشطة بتوقيتها للجزء العربي والثقافي، المواد، الواجب المرتبط | R1 |
| CNT-05 | موارد المعلمة | الشرائح ومفاتيح الإجابة وأدلة التدريس، للمعلمات فقط | R1 |
| CNT-06 | مسودة ونشر وأرشفة | لا حذف لمحتوى استُخدم في دروس أو تقارير سابقة، بل أرشفة | R1 |
| CNT-07 | مكتبة الوسائط | وسوم وبحث وبيانات الترخيص: المصدر، نوع الرخصة، تاريخ الانتهاء | R1 |
| CNT-08 | الطباعة العربية | خطوط مستضافة تدعم التشكيل، تكبير الخط، وإظهار التشكيل أو إخفاؤه | R1 |
| CNT-09 | إطار المستويات | عبارات «يستطيع أن» لكل مستوى، تُستخدم في التقييم والتقارير | R1 |
| CNT-10 | الإصدارات | سجل نسخ لكل عنصر مع إمكانية الرجوع | R2 |
| CNT-11 | رموز QR | رمز ثابت لكل عنصر يُطبع في الكراسات ويحوّل إلى المحتوى حسب الصلاحية | R2 |
| CNT-12 | أنشطة تفاعلية | منشئ أنشطة: سحب وإفلات، توصيل، ترتيب حروف، بطاقات صوتية | R2 |
| CNT-13 | كراسة المستوى | تصدير كراسة PDF لكل مستوى | R2 |
| CNT-14 | قراءة آلية بالعربية | تحويل النص إلى صوت لتسريع إنتاج مواد النطق، بمراجعة بشرية | R3 |

### التقييم وتحديد المستوى

| المعرّف | الميزة | التفاصيل | الأولوية |
| --- | --- | --- | --- |
| ASM-01 | اختبار المستوى الأولي | أسئلة بالصور والصوت تناسب الصغار، تصحيح آلي، نطاق مستوى مقترح | R1 |
| ASM-02 | نموذج المقابلة الشفوية | معايير من 1 إلى 5: النطق ومخارج الحروف، الاستماع، المحادثة، القراءة، الكتابة، المعرفة الإسلامية حسب العمر؛ مع توصية | R1 |
| ASM-03 | قرار التسكين | يعتمده المشرف الأكاديمي، ويُسجل في تاريخ الطالب | R1 |
| ASM-04 | منشئ الاختبارات | اختيار من متعدد، توصيل، ترتيب، إكمال، إجابة قصيرة، إجابة صوتية؛ وأسئلة عربية خاصة: أشكال الحرف في أول الكلمة ووسطها وآخرها، الحركات، الإملاء من تسجيل صوتي | R2 |
| ASM-05 | المحاولات والتصحيح | نوافذ إتاحة، مؤقت، عدد محاولات، تصحيح آلي، وتصحيح يدوي للأسئلة المفتوحة | R2 |
| ASM-06 | حجب النتيجة | لا تظهر للطالب والأسرة حتى تنشرها المعلمة | R2 |
| ASM-07 | بنك الأسئلة | وسوم بالمستوى والمهارة والصعوبة | R2 |
| ASM-08 | شهادة المستوى | شهادة PDF عند اجتياز اختبار نهاية المستوى | R2 |

### الواجبات

| المعرّف | الميزة | التفاصيل | الأولوية |
| --- | --- | --- | --- |
| HW-01 | منشئ الواجب | العنوان، التعليمات بالعربية والإنجليزية، نوع التسليم، الموعد بتوقيت الشعبة، المرفقات، الدرس المرتبط | R1 |
| HW-02 | أنواع التسليم | نص بلوحة المفاتيح العربية، صورة لخط اليد، تسجيل صوتي حتى 3 دقائق، ملف | R1 |
| HW-03 | إعادة التسليم | مسموحة حتى الإغلاق، مع حفظ كل نسخة | R1 |
| HW-04 | التصحيح | درجة أو معيار تقييم + ملاحظة نصية، تظهر للطالب وولي الأمر بعد النشر | R1 |
| HW-05 | التأخير والتذكير | سياسة تأخير قابلة للإعداد، وتذكير قبل الموعد بيوم | R1 |
| HW-06 | إزالة بيانات الصور | حذف بيانات الموقع والجهاز من الصور المرفوعة تلقائياً | R1 |

### التقارير الأكاديمية

| المعرّف | الميزة | التفاصيل | الأولوية |
| --- | --- | --- | --- |
| RPT-01 | مؤشرات أسبوعية لكل طالب | الحضور تلقائياً، المشاركة من 1 إلى 5، حالة الواجب، مهارة الأسبوع، ملاحظة اختيارية؛ نحو دقيقتين | R1 |
| RPT-02 | ملخص أسبوعي للشعبة | المواضيع المغطاة من خطة الدرس، الواجب، أهداف الأسبوع القادم؛ مرة واحدة لكل الشعبة | R1 |
| RPT-03 | تقرير شهري مفصل | القراءة والكتابة والاستماع والمحادثة، ملاحظات القيم والثقافة الإسلامية، توصيات | R1 |
| RPT-04 | مهام التقارير | تُنشأ تلقائياً بمواعيد استحقاق، مع تنبيه تأخير للمعلمة والمشرف | R1 |
| RPT-05 | المراجعة بالعينة | كل تقارير المعلمة الجديدة لثلاثة أشهر، ثم 20% عشوائياً؛ مع «إعادة للتعديل» بتعليق | R1 |
| RPT-06 | النشر والاطلاع | إشعار لولي الأمر، وتسجيل وقت الاطلاع، وتنزيل PDF بخط عربي سليم التشكيل والوصل | R1 |
| RPT-07 | تقرير المستوى | بعد اختبار نهاية المستوى، مع قرار الانتقال أو الإعادة | R2 |
| RPT-08 | قوالب قابلة للتعديل | يحررها المشرف الأكاديمي ومدير المحتوى | R2 |
| RPT-09 | مسودة بمساعدة الذكاء الاصطناعي | صياغة أولية للتقرير الشهري من المؤشرات وملاحظات المعلمة، تراجعها المعلمة قبل النشر | R3 |
