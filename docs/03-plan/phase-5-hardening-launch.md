| البند | القيمة |

4. **الوثائق:**
   - دليل تدوير الأسرار.
   - وثيقة نطاق اختبار الاختراق.
5. **المعالجة:** إغلاق كل ملاحظة حرجة أو عالية قبل ب3.

### WP-5.2 الخصوصية والامتثال

| البند | القيمة |
| --- | --- |
| النافذة | الأسابيع 18–26 |
| يعتمد على | WP-1.5، WP-3.3 |
| القرارات | D-14، D-15 |
| المتطلبات | PRV-04..10 · مهام الاحتفاظ لكل جدول (`spec/17` + D-15) |
| اقرأ فقط | `spec/17` (PRV، جدول الاحتفاظ) · ADR-009 · `decisions.md` (D-13..D-16) · مهارة child-privacy |
| المراجعات | privacy-reviewer |
| مهام صاحب المشروع | اعتماد تقييم أثر حماية البيانات؛ توقيع اتفاقيات المعالجة |

**المخرجات:**
1. **مهام الاحتفاظ:** مهمة مجدولة لكل نوع بيانات بدور `sura_retention`، مع تسجيل كل حذف.
2. **تقييم الأثر:** جرد بيانات يُولَّد من `config/privacy.php` لدعمه (PRV-09).
3. **المزودون:** سجلهم وقائمة اتفاقيات المعالجة والنقل (PRV-08).
4. **قائمة مطابقة معايير تصميم خدمات الأطفال في بريطانيا** (PRV-09).
5. **التدقيق الآلي لغياب المتتبعات (PRV-10):** فحص الشبكة في Playwright لصفحات الطفل.
6. **حقوق الأسرة:** صيغة حزمة تصدير البيانات (JSON + PDF)، واختبار طرفي للحذف (PRV-07).

**معايير القبول:**
- [ ] privacy-reviewer دون ملاحظة حاجبة.
- [ ] تقييم الأثر معتمد.

   - حادث تسرب بيانات خلال 72 ساعة (SEC-14).
4. **تمرين استعادة كامل:** هدف الاستعادة 4 ساعات، ونقطة الاستعادة 15 دقيقة.
