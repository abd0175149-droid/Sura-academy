# specs/

مجلد عمل حزم التنفيذ. يُنشئه `/sura-wp` لكل حزمة:

```text
specs/WP-2.3/
├── design.md   التصميم المعتمد من صاحب المشروع قبل الكود
├── tasks.md    المهام المرقمة مع أوامر التحقق (✓ عند الإنجاز)
└── notes.md    القرارات المطبقة، أدلة التحقق، ملاحظات المراجعة، خطوات العرض اليدوي
```

هذه الملفات جزء من سجل المشروع وتُدمج مع الكود في الـ PR نفسه.
