## بوابة الطالب وحساب الطفل المُدار

حساب الطفل يُنشئه ولي الأمر ويديره، ولا يحمل بريداً إلكترونياً ولا بيانات اتصال. الواجهة مصممة لطفل لا يقرأ الإنجليزية جيداً ولا يملك لوحة مفاتيح عربية.

| المعرّف | الميزة | التفاصيل | الأولوية |
| --- | --- | --- | --- |
| STU-01 | الدخول | من جهاز ولي الأمر عبر «وضع الطفل» ورمز PIN، أو على جهاز الطفل برمز لمرة واحدة أو QR من بوابة ولي الأمر | R1 |
| STU-02 | الشاشة الرئيسية | عداد الحصة القادمة، زر «ادخل الحصة» يتفعل في نافذة الدخول فقط، «تابع التعلم»، الواجبات المفتوحة، نجوم التقدم | R1 |
| STU-03 | فحص الجهاز | اختبار الكاميرا والميكروفون والسماعة وسرعة الاتصال قبل الحصة، بتعليمات مصورة وصوتية | R1 |
| STU-04 | دخول الحصة | الفصل مدمج في الصفحة دون تثبيت برنامج، بدور «طالب» وصلاحيات محدودة | R1 |
| STU-05 | الدروس والمحتوى | الوحدات حسب مستواه: صفحات نصية مشكولة، فيديو، صوت للنطق، أوراق عمل PDF، روابط | R1 |
| STU-06 | الواجبات | قراءة الواجب وتسليمه نصاً أو صورة لخط اليد أو تسجيلاً صوتياً للقراءة أو ملفاً، ثم رؤية الملاحظات | R1 |
| STU-07 | لوحة مفاتيح عربية على الشاشة | للطفل الذي لا يملك لوحة عربية، بأحجام حروف كبيرة وتشكيل اختياري | R1 |
| STU-08 | التسجيلات | حصص شعبته فقط، ضمن مدة الاحتفاظ ووفق موافقة ولي الأمر، دون تنزيل | R1 |
| STU-09 | التقدم | نجوم ومستويات بسيطة مرتبطة بالحضور والواجبات | R1 |
| STU-10 | الإعلانات | من الأكاديمية فقط، ولا تواصل مباشر مع المعلمة أو الطلاب خارج الحصة | R1 |
| STU-11 | إمكانية الاستخدام للصغار | أهداف لمس لا تقل عن 44 بكسل، تعليمات صوتية لمن لم يتقن القراءة، أقل نص ممكن | R1 |
| STU-12 | الاختبارات القصيرة | اختيار من متعدد، توصيل، ترتيب حروف، استماع، مع تصحيح آلي | R2 |
| STU-13 | لوحة كتابة بخط اليد | رسم الحروف بالإصبع أو القلم على الجهاز اللوحي وتسليمها واجباً | R2 |
| STU-14 | ألعاب ومكافآت متقدمة | شارات ومتجر جوائز، خارج نطاق الوثيقة الأصلية للنسخة الأولى | R3 |

أمور ممنوعة في واجهة الطفل: أي معلومة مالية، بيانات اتصال المعلمة أو الطلاب الآخرين، روابط إلى مواقع خارجية دون تنبيه، إعلانات أو أدوات تتبع تسويقية.
