## الإشعارات والتواصل والدعم

كل رسالة تخرج من محرك واحد: حدث في النظام ← قالب بلغة المستلم ← القناة التي اختارها ← توقيت يحترم منطقته الزمنية وساعات الهدوء ← سجل تسليم. لا تواصل مباشر بين المعلمة والطفل خارج المنصة، ولا تُعرض بيانات اتصال أي طرف للآخر.

| المعرّف | الميزة | التفاصيل | الأولوية |
| --- | --- | --- | --- |
| NOT-01 | محرك الإشعارات | ربط الأحداث بالقوالب والقنوات، جدولة حسب توقيت المستلم، ساعات هدوء 21:00–08:00 افتراضياً | R1 |
| NOT-02 | البريد الإلكتروني | قناة أساسية لكل الإشعارات، بنطاق مرسل موثق SPF وDKIM وDMARC | R1 |
| NOT-03 | صندوق داخل التطبيق | كل إشعار يظهر أيضاً داخل البوابة مع حالة المقروء | R1 |
| NOT-04 | الرسائل النصية | لرموز التحقق والتنبيهات العاجلة فقط | R1 |
| NOT-05 | واتساب للأعمال | تذكير الحصص والتقارير والدفعات بقوالب معتمدة من Meta، بموافقة الأسرة على القناة | R2 |
| NOT-06 | إشعارات المتصفح | للتطبيق المثبت على الهاتف | R2 |
| NOT-07 | القوالب | عربي وإنجليزي، متغيرات، إصدارات، معاينة، إرسال تجريبي | R1 |
| NOT-08 | الرسائل الجماعية | لشعبة أو مستوى أو دولة، بصلاحية محددة، مع سجل لمن أُرسلت | R1 |
| NOT-09 | سجل التسليم | مرسل، مُسلَّم، مرتد، فاشل؛ مع إعادة محاولة الفاشل وإيقاف العناوين المرتدة | R1 |
| MSG-01 | تذاكر الدعم | تصنيف، إسناد لموظف، ملاحظات داخلية، مرفقات، مؤقت مستوى الخدمة، تقييم الرضا | R1 |
| MSG-02 | مستويات الخدمة | رد أول خلال 12 ساعة، وخلال ساعة لمشكلات الدخول قبل الحصة | R1 |
| MSG-03 | إعلانات للطلاب | من الأكاديمية فقط، بلغة مناسبة للعمر | R1 |
| MSG-04 | تواصل ولي الأمر والمعلمة | محادثات داخل المنصة حول الطالب، ظاهرة للمشرف، دون أرقام هواتف | R2 |
| MSG-05 | مركز مساعدة | مقالات للأسئلة المتكررة: فحص الجهاز، الغياب، الدفع | R2 |

قائمة الإشعارات الآلية كاملة بمحفزاتها ومستلميها وقنواتها في الملحق آخر الوثيقة.
