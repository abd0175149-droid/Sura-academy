## الأمن والخصوصية وحماية الطفل

الامتثال لقاعدة COPPA المعدلة شرط قبل الإطلاق لا بعده: الامتثال الكامل لتعديلاتها مطلوب منذ 22 أبريل 2026 ([Bass, Berry & Sims](https://bassberry.com/news/amendments-to-the-coppa-rule-now-in-effect/)). ولأن المنصة تجمع فيديو وصوت أطفال، تُصمم الخصوصية من الجدول الأول، ويُراجع كل ما يلي مع مستشار قانوني في الأسواق المستهدفة.

### الأمن

| المعرّف | الضابط | الأولوية |
| --- | --- | --- |
| SEC-01 | تخزين كلمات المرور بخوارزمية Argon2id، وحد أدنى 10 أحرف، ومنع كلمات المرور المسربة الشائعة | R1 |
| SEC-02 | تحقق ثنائي (TOTP) إلزامي لكل أدوار الموظفين والمعلمات، واختياري لأولياء الأمور | R1 |
| SEC-03 | جلسات بملفات ارتباط آمنة، تدوير عند الدخول، انتهاء بعد 30 دقيقة خمول للموظفين، قائمة أجهزة وخروج من كل الأجهزة | R1 |
| SEC-04 | رمز PIN للطفل من 4 إلى 6 أرقام مخزن مشفراً، يعمل على جهاز فوّضه ولي الأمر فقط، ويُقفل 15 دقيقة بعد 5 محاولات | R1 |
| SEC-05 | فحص الصلاحية ونطاق البيانات في الخادم لكل طلب، مع اختبارات آلية لكل دور | R1 |
| SEC-06 | حماية من حقن SQL وXSS وCSRF وSSRF، وسياسة أمان محتوى (CSP) صارمة | R1 |
| SEC-07 | حدود استخدام على الدخول ورموز التحقق والتسجيل واستعادة كلمة المرور والنماذج العامة | R1 |
| SEC-08 | TLS 1.2 فأعلى مع HSTS، وتشفير البيانات المخزنة، وتشفير إضافي للحقول الحساسة مثل البيانات البنكية للمعلمات | R1 |
| SEC-09 | الملفات المرفوعة: قائمة امتدادات مسموحة، حد للحجم، فحص فيروسات، حذف بيانات الموقع من الصور، عرض بروابط موقعة | R1 |
| SEC-10 | التسجيلات: تخزين خاص، روابط عرض صالحة 10 دقائق، تعطيل التنزيل للأسر، تسجيل كل وصول، حذف آلي عند انتهاء المدة | R1 |
| SEC-11 | سجل تدقيق للإضافة فقط: الفاعل، الفعل، الكيان، القيمة قبل وبعد، العنوان، الوقت؛ يُحفظ سنتين على الأقل | R1 |
| SEC-12 | لا بيانات شخصية في السجلات: إخفاء البريد والهاتف، ولا أسماء أطفال في أي أداة خارجية | R1 |
| SEC-13 | فحص الاعتماديات آلياً، واختبار اختراق خارجي قبل الإطلاق ثم سنوياً | R1 |
| SEC-14 | خطة استجابة للحوادث: إيقاف حساب أو كل الجلسات فوراً، ومهل الإبلاغ حسب كل قانون (72 ساعة للسلطة في GDPR) | R1 |

### الخصوصية

| المعرّف | المتطلب | الأولوية |
| --- | --- | --- |
| PRV-01 | إشعار مباشر لولي الأمر قبل جمع بيانات الطفل، يسمي الأطراف الثالثة التي تتلقاها وأغراضها | R1 |
| PRV-02 | موافقة أبوية قابلة للتحقق بطريقة يعتمدها المستشار القانوني، مثل معاملة الدفع بالبطاقة عند الاشتراك أو طريقة «الرسالة النصية مع خطوة تأكيد إضافية» | R1 |
| PRV-03 | موافقة منفصلة لأي مشاركة لبيانات الطفل مع طرف ثالث لا تحتاجها الخدمة نفسها، والمنصة لا تشارك بيانات الأطفال لأغراض إعلانية إطلاقاً | R1 |
| PRV-04 | الحد الأدنى من بيانات الطفل: الاسم الأول، الشهر والسنة للميلاد، معلومات المستوى؛ لا صورة ولا بريد ولا عنوان | R1 |
| PRV-05 | برنامج أمن معلومات مكتوب: منسق مسؤول، تقييم مخاطر سنوي، اختبار ومراقبة مستمران، ومراجعة سنوية للضوابط | R1 |
| PRV-06 | سياسة احتفاظ منشورة تذكر الغرض ومدة الحذف لكل نوع من بيانات الأطفال (الجدول أدناه) | R1 |
| PRV-07 | حق ولي الأمر في الاطلاع والتصحيح والحذف ووقف الاستخدام، عبر طلب من البوابة ومهلة استجابة 30 يوماً | R1 |
| PRV-08 | اتفاقية معالجة بيانات مع كل مزود (الفيديو، البريد، الاستضافة، الدفع)، وآلية نقل معتمدة للبيانات الأوروبية والبريطانية | R1 |
| PRV-09 | تقييم أثر لحماية البيانات قبل الإطلاق، وتطبيق معايير تصميم خدمات الأطفال في بريطانيا: خصوصية عالية افتراضياً، لا تحديد للموقع، لا تنميط | R1 |
| PRV-10 | لا إعلانات ولا أدوات تتبع تسويقية في أي صفحة يراها الطفل؛ أدوات التسويق في الصفحات العامة فقط وبموافقة | R1 |

### جدول الاحتفاظ بالبيانات

| نوع البيانات | مدة الاحتفاظ | بعدها |
| --- | --- | --- |
| تسجيلات الحصص | 30 يوماً للأسر، 90 يوماً للإدارة | حذف نهائي من التخزين |
| ملفات الواجبات والتسجيلات الصوتية | 12 شهراً بعد مغادرة الطالب | حذف نهائي |
| التقارير والدرجات | 3 سنوات بعد مغادرة الطالب | حذف أو إخفاء الهوية |
| السجلات المالية | حسب القانون الأردني ومتطلبات المحاسبة | أرشيف مقيد الوصول |
| العملاء المحتملون دون اشتراك | 12 شهراً | حذف |
| سجلات النظام التقنية | 12 شهراً | حذف |
| سجل التدقيق | سنتان على الأقل | أرشيف |

### حماية الطفل

| المعرّف | المتطلب | الأولوية |
| --- | --- | --- |
| SAFE-01 | زر «الإبلاغ عن مخاوف» لولي الأمر والمعلمة، يصل مسؤول الحماية خلال 24 ساعة كحد أقصى | R1 |
| SAFE-02 | سجل بلاغات مقيد الوصول لمسؤول الحماية ومدير النظام، بكل خطوة متخذة | R1 |
| SAFE-03 | لا رسائل خاصة غير مراقبة بين بالغ وطفل، ولا مشاركة لبيانات الاتصال | R1 |
| SAFE-04 | المعلمة لا تُفعّل قبل رفع شهادة عدم المحكومية وإكمال تدريب حماية الطفل والإقرار بمدونة السلوك | R1 |
| SAFE-05 | زيارات إشرافية ظاهرة للحصص، ووصول المشرف للتسجيلات عند البلاغ فقط مع تسجيل الوصول | R1 |
| SAFE-06 | إيقاف فوري لحساب المعلمة وحجب دخولها للحصص عند بلاغ جدي، مع إعادة إسناد شعبها | R1 |
