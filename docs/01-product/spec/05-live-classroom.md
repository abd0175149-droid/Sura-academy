## الفصل الافتراضي وأدوات الحصة المباشرة

الفيديو لا يُبنى من الصفر: يُدمج مزود جاهز داخل صفحات المنصة، والمنصة تتحكم بمن يدخل ومتى وبأي دور. [Zoom Video SDK للويب](https://developers.zoom.us/docs/video-sdk/web/) هو المرشح الأول، ويتيح واجهة مخصصة أو مجموعة واجهات جاهزة؛ أدوات مثل السبورة والتعليق على الشاشة تُتحقق في التجربة التقنية قبل اعتمادها.

| المعرّف | الأداة أو الميزة | التفاصيل | الأولوية |
| --- | --- | --- | --- |
| CLS-01 | فيديو وصوت مدمجان | في المتصفح دون تثبيت، على الحاسوب وiPad وكروم بوك والأجهزة اللوحية؛ الهاتف مسموح مع تنبيه | R1 |
| CLS-02 | نافذة الدخول | تُفتح قبل الحصة بعشر دقائق (إعداد) وتُغلق بعد نهايتها؛ زر الدخول معطل خارجها | R1 |
| CLS-03 | رمز دخول من الخادم | رمز قصير العمر لكل مستخدم وحصة ودور، لا رابط ثابت قابل للمشاركة | R1 |
| CLS-04 | الأدوار داخل الغرفة | المعلمة مضيفة: كتم الجميع، إخراج مشارك، تثبيت فيديو، قفل الغرفة؛ الطالب مشارك دون مشاركة شاشة افتراضياً | R1 |
| CLS-05 | منع الغرباء | لا يدخل إلا المسجلون في الشعبة والمعلمة والبديلة المكلفة والمشرف | R1 |
| CLS-06 | مشاركة الشاشة والصوت | المعلمة تعرض الشرائح وأوراق العمل وتشغّل مقاطع استماع بصوت واضح | R1 |
| CLS-07 | الدردشة داخل الحصة | عامة فقط، تستطيع المعلمة إيقافها، ومحفوظة في السجل؛ لا رسائل خاصة بين طالب وآخر أو بين المعلمة وطالب | R1 |
| CLS-08 | رفع اليد والتفاعلات وكتم الذات | أدوات مشاركة بسيطة للأطفال | R1 |
| CLS-09 | الحضور الآلي | أحداث الدخول والخروج من المزود تُحسب دقائق الحضور وتقترح الحالة، والمعلمة تؤكدها | R1 |
| CLS-10 | التسجيل السحابي | يبدأ تلقائياً عند موافقة كل أسر الشعبة، ويُخزن خاصاً، ويُعرض بروابط موقعة قصيرة العمر | R1 |
| CLS-11 | مساحة عمل المعلمة | بجانب الفيديو: قائمة الطلاب مع أزرار الحضور، خطة الدرس، الملاحظات، مؤشرات التقرير السريعة، قائمة إنهاء الحصة | R1 |
| CLS-12 | زر البلاغ الطارئ | للمعلمة: مشكلة تقنية أو مخاوف تتعلق بحماية طفل، يصل فوراً للعمليات أو مسؤول الحماية | R1 |
| CLS-13 | دخول البديلة والمشرف | رمز للحصة المحددة فقط؛ المشرف يظهر باسم «مشرفة» ولا يدخل خفياً | R1 |
| CLS-14 | وضع الاتصال الضعيف | التحول إلى الصوت فقط وخفض جودة الفيديو تلقائياً | R1 |
| CLS-15 | رابط احتياطي | إذا فشل الدمج، تولّد العمليات رابطاً بديلاً للحصة نفسها مع تسجيل السبب | R1 |
| CLS-16 | السبورة والكتابة على المعروض | لتدريب كتابة الحروف؛ من المزود إن توفرت، وإلا سبورة مدمجة مستقلة بمزامنة لحظية | R2 |
| CLS-17 | عارض شرائح داخلي | فتح درس من المكتبة داخل الغرفة بدل مشاركة الشاشة | R2 |
| CLS-18 | مؤقت الأنشطة | مؤقت ظاهر للجزء العربي والاستراحة والجزء الثقافي | R2 |
| CLS-19 | نجوم داخل الحصة | المعلمة تمنح نجوماً تظهر في تقدم الطالب | R2 |
| CLS-20 | علامة مائية في التسجيلات | اسم الحساب أو رقم الجلسة على التسجيل عند العرض | R2 |

### قواعد الحصة التي يفرضها النظام

- لا تبدأ الحصة دون معلمة مكلفة؛ تأخر المعلمة خمس دقائق ينبه العمليات.
- كاميرا المعلمة مفتوحة طوال الحصة، والطالب يستطيع إغلاق كاميرته ويبقى صوته متاحاً.
- كل دخول وخروج ومشاركة شاشة وتسجيل يُحفظ في سجل الحصة.
- عند انتهاء الوقت تبقى الغرفة مفتوحة عشر دقائق ثم تُغلق تلقائياً.
