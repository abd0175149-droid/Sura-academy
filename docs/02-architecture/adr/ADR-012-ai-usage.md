# ADR-012: سياسة الذكاء الاصطناعي

- الحالة: Accepted · مرتبط بـ CR-002، D-26

## القرار
1. **في المنتج R1:** لا ميزات ذكاء اصطناعي.
2. **R2 (بعد اعتماد CR):** مساعد للمعلمات فقط، والمعلمة تراجع كل مخرج قبل وصوله لطفل أو أسرة.
3. **R3:** أي تفاعل آلي مع الطفل يحتاج موافقة أبوية منفصلة، ونطاقاً محصوراً في الدرس، وإفصاحاً بأنه آلي، ومراجعة قانونية للقوانين المحلية.
4. **دائماً:** لا اسم طفل ولا بيانات شخصية في المدخلات؛ مزود لا يستخدم البيانات للتدريب؛ لا فتاوى ولا نصوص شرعية مولّدة.
5. **في التطوير:** Claude Code أداة التطوير الأساسية، ولا يُعطى أي بيانات إنتاجية حقيقية.
