# ADR-005: مزود الفيديو خلف محوّل

- الحالة: Proposed — يُحسم بنهاية WP-0.4 (الأسبوع 3) · مرتبط بـ D-20، CR-001

## السياق
المواصفات ترشح Zoom Video SDK بعد تجربة تقنية لأسبوعين. مع Flutter: حزمة Zoom Video SDK لـ Flutter تغلّف iOS وAndroid فقط ولا تدعم الويب، فالويب يحتاج تكامل JavaScript منفصلاً. حزمة LiveKit لـ Flutter تدعم الويب وiOS وAndroid وسطح المكتب.

## القرار الثابت (مهما كان المزود)
1. واجهة `VideoProvider` في الخادم (إنشاء غرفة، رمز دخول بدور وصلاحيات، إنهاء، جلب التسجيل، التحقق من webhooks) وواجهة `VideoClient` في `sura_classroom`.
2. الدخول برمز قصير العمر يصدره الخادم فقط داخل نافذة الدخول (CLS-02/03).
3. الأدوار: معلمة (مضيفة)، طالب، بديلة، مشرف (CLS-04/05/13).
4. التسجيل يُنسخ إلى S3 الأوروبي ويُحذف من المزود (D-16).

## معايير الاختيار (تقيسها WP-0.4)
| المعيار | الحد |
| --- | --- |
| عمل الفصل على ويب Flutter (Chrome، Safari على iPad)، وiOS وAndroid | إلزامي |
| زمن الدخول حتى ظهور الفيديو | ≤ 10 ث عند 95% |
| الأداء عند 1.5 ميغابت والتحول للصوت | مقبول بمراقبة يدوية |
| أحداث الدخول والخروج للحضور الآلي | متاحة عبر webhook |
| التسجيل السحابي وإمكانية التنزيل | متاح |
| التحكم بالأدوار والكتم وإخراج المشارك | متاح |
| التكلفة لـ 100 حصة متزامنة × 4 مشاركين | محسوبة ومقارنة |
| منطقة بيانات أوروبية أو حذف بعد النسخ | متاح |

## القرار
(يُكتب هنا بعد WP-0.4 مع أرقام التجربة.) الافتراض في حال تساوي النتائج: LiveKit Cloud لأن تطبيقاً واحداً بـ Flutter يغطي الويب والهاتف.
